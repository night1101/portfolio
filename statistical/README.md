## Сравнение критериев проверки гипотез

**Задача:** Проверить, различаются ли средние двух нормальных выборок.

**Методы:**
- Критерий отношения правдоподобия (LR)
- t-критерий Стьюдента
- Непараметрический U-критерий Манна-Уитни

**Результат:** Все три критерия дают согласованный результат (p > 0.05).

**Ключевые выводы:**
1. При нормальных данных t-тест и LR-тест эквивалентны
2. U-тест (ранговый) менее мощный, но устойчив к выбросам
3. Визуализация (box-plot, гистограммы) помогает интерпретировать результаты
