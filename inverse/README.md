## Генерация выборки и оценка параметра распределения p(x|θ) = θ·(1-x)^(θ-1)

**Задача:** Сгенерировать выборку из заданного распределения, оценить параметр θ и построить доверительный интервал.

**Методы:**
- Генерация методом обратного преобразования
- Оценка максимального правдоподобия (ОМП)
- Метод моментов (ММ)
- Асимптотический доверительный интервал
- Ядерная оценка плотности (KDE)

**Результат:** ОМП дала оценку θ̂ = 2.069, что очень близко к истинному значению θ = 2. Доверительный интервал [1.495, 2.642] накрыл истинное значение.

**Ключевые выводы:**
1. Метод обратного преобразования корректно генерирует выборку из заданного распределения (гистограмма и KDE близки к теоретической плотности)
2. ОМП и метод моментов дали схожие оценки (θ̂_MLE = 2.069, θ̂_MM = 2.060)
3. Асимптотический доверительный интервал построен на основе свойства нормальности ОМП для больших выборок
4. Визуализация (ECDF, гистограмма, KDE, теоретическая плотность) подтверждает качество генерации и оценок

**Графики:**
- Эмпирическая функция распределения
- Сравнение гистограммы, KDE и теоретической плотности
